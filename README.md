# key_generator_tools

🛡️ Secure Key & Password Generator (CSPRNG)

เครื่องมือเว็บแอปพลิเคชันแบบหน้าเดียว (Single-Page Application) สำหรับสร้างคีย์เข้ารหัสลับ (Cryptographic Keys) และสุ่มรหัสผ่านความปลอดภัยสูง (Secure Passwords) ทำงานบนระบบปิด (Client-Side 100%) ปลอดภัยเทียบเท่าการใช้งานผ่าน Command Line (CMD)

🌟 จุดเด่นของระบบ (Core Features)

การสุ่มระดับการเข้ารหัสลับ (CSPRNG): ใช้เทคโนโลยี window.crypto.getRandomValues ดึงค่าความย่อยยับทางคณิตศาสตร์สุ่ม (Entropy) จากระดับฮาร์ดแวร์ของระบบปฏิบัติการโดยตรง แตกต่างจาก Math.random() ทั่วไป

ปลอดภัยแบบ Zero-Server / Zero-Trust: โค้ดทั้งหมดประมวลผลบนหน่วยความจำชั่วคราว (RAM) บนเบราว์เซอร์ของคุณ ไม่มีฐานข้อมูล ไม่มีการบันทึกคุกกี้ และไม่มีการส่งข้อมูลคีย์ออกไปยังเซิร์ฟเวอร์ภายนอกแม้แต่ไบต์เดียว

ตัววิเคราะห์ความเข้มแข็งของคีย์ (Security Metrics): คำนวณค่าความยากในการถอดรหัส (Entropy Strength) ในหน่วย "bits" แบบเรียลไทม์ พร้อมแสดงสถานะความแข็งแกร่งของรหัส

ส่งออกคีย์อย่างปลอดภัยผ่าน QR Code ออฟไลน์: ใช้ไลบรารี QRious ในการวาดรูปภาพลงบนแคนวาสอินเทอร์เฟซเครื่องคอมพิวเตอร์ของคุณโดยตรง ไม่ผ่าน API ของบุคคลที่สาม ช่วยให้สแกนนำคีย์ไปใช้บนโทรศัพท์มือถือได้อย่างปลอดภัย

รองรับโหมดตัดขาดจากอินเทอร์เน็ต (Air-Gapped / Offline-Ready): สามารถเปิดรันหน้าเว็บได้แม้ในโหมดเครื่องบิน (Airplane Mode)

เครื่องมือจัดการผลลัพธ์ครบครัน: สามารถดาวน์โหลดคีย์ทั้งหมดออกเป็นไฟล์ข้อความ .txt หรือคัดลอกลงคลิปบอร์ดแบบปลอดภัย (iFrame-Safe Copy)

🛠️ วิธีการติดตั้งและใช้งาน (Installation & Quick Start)

แอปพลิเคชันนี้ได้รับการออกแบบให้อยู่ในรูปแบบ Single File HTML เพื่อความสะดวกและปลอดภัยสูงสุดในการตรวจสอบโค้ด

วิธีเปิดใช้งานทั่วไป

ดาวน์โหลดหรือบันทึกไฟล์ secure_key_generator.html ลงในเครื่องคอมพิวเตอร์ของคุณ

ดับเบิลคลิกเปิดไฟล์ด้วยเว็บเบราว์เซอร์ใดก็ได้ (เช่น Google Chrome, Microsoft Edge, Firefox, หรือ Safari)

เริ่มต้นสร้างคีย์หรือรหัสผ่านได้ทันที

🔒 วิธีใช้งานในโหมดปลอดภัยขั้นสูงสุด (Air-Gapped Sandbox)

เพื่อความสบายใจสูงสุดในการสร้างคีย์ระดับความลับทางราชการหรือบัญชีสินทรัพย์ดิจิทัล (Crypto Wallet Key) แนะนำให้ปฏิบัติตามนี้:

บันทึกไฟล์เว็บแอปนี้ลงแฟลชไดรฟ์ (USB Drive)

นำไปเสียบเปิดใช้งานบนคอมพิวเตอร์ที่ไม่ได้เชื่อมต่ออินเทอร์เน็ต (Air-Gapped PC) หรือกดตัดสัญญาณอินเทอร์เน็ต/เปิดโหมดเครื่องบินบนอุปกรณ์ของคุณก่อนสุ่มคีย์

ทำการสุ่มคีย์และจดบันทึกให้เรียบร้อยก่อนปิดแท็บเบราว์เซอร์

🔬 การตรวจสอบความปลอดภัยและความโปร่งใส (Security Audit)

คุณสามารถตรวจสอบความโปร่งใสของระบบได้ด้วยตัวเองผ่านขั้นตอนง่ายๆ ดังนี้:

1. พิสูจน์ว่าไม่มีการส่งข้อมูลออกนอกเครื่อง (No Outbound Data Traffic)

เปิดไฟล์แอปพลิเคชันขึ้นมา

กดปุ่ม F12 หรือคลิกขวาเลือก "ตรวจสอบ" (Inspect) แล้วไปที่แท็บ "เครือข่าย" (Network)

ลองกดปุ่ม "สุ่มข้อมูลความปลอดภัยสูง" ซ้ำๆ

ผลลัพธ์การตรวจสอบ: คุณจะไม่พบทราฟฟิกเครือข่ายวิ่งออกไปภายนอกเลยแม้แต่รายการเดียวในหน้าคอนโซล

2. พิสูจน์การทำงานแบบ Offline สมบูรณ์แบบ

ปิดการเชื่อมต่อ Wi-Fi หรือดึงสายแลนอินเทอร์เน็ตออก

กดรีเฟรชหน้าเว็บแอป (หรือดับเบิลคลิกเปิดไฟล์ขึ้นมาใหม่)

ระบบจะเปลี่ยนสถานะการเชื่อมต่อเป็น "ออฟไลน์สมบูรณ์แบบ (ปลอดภัยขั้นสุด)" สีเขียวตรงแผงควบคุม และคุณยังคงกดสุ่มคีย์รวมถึงสร้าง QR Code ได้ตามปกติอย่างปลอดภัย
